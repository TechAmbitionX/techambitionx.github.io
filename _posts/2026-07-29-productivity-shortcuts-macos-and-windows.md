# Productivity Shortcuts Cheat Sheet: macOS & Windows OS

Please don't expect yourself to memorize every single key combination overnight. But learning and using even a handful of these navigation, screen management, and browser shortcuts "can" instantly eliminate repetitive mouse movements, probably saving you hours every single week. Bookmark this guide, open your terminal or browser, and start practicing!

---

## 🖥️ 1. Window Management and and Multi-Screen

### Window Snapping & Display Layouts

| Action | Windows OS | macOS |
| :--- | :--- | :--- |
| **Snap window to left / right half** | `Win` + `Left` / `Right` | `Fn` + `Control` + `Left` / `Right` *(macOS Sequoia+)* |
| **Maximize / Restore window** | `Win` + `Up` / `Down` | `Fn` + `Control` + `F` |
| **Open Task View / Mission Control** | `Win` + `Tab` | `Control` + `Up Arrow` |
| **Create new Virtual Desktop / Space** | `Win` + `Ctrl` + `D` | System Settings → Keyboard → Add Space |
| **Close current Virtual Desktop** | `Win` + `Ctrl` + `F4` | Hover in Mission Control → `Option` + `X` |

---

### Moving Windows Between Screens

When working with multiple monitors, shifting active windows across displays seamlessly "can" be a massive productivity booster.

| Action | Windows OS | macOS |
| :--- | :--- | :--- |
| **Move window to adjacent screen** | `Win` + `Shift` + `Left` / `Right` | *Requires third-party app (e.g., Rectangle: `Ctrl` + `Option` + `Cmd` + `Left` / `Right`)* |
| **Switch Spaces / Fullscreen Apps across screens** | `Ctrl` + `Win` + `Left` / `Right` | `Control` + `Left` / `Right` |

> **macOS Power Tip:** macOS does not feature a single native hotkey to move floating windows between displays. Installing a lightweight, open-source tool like **Rectangle** adds instant `Control` + `Option` + `Command` + `Arrow` shortcuts to move windows across screens effortlessly.

## ✍️ 3. Power Text Editing & Cursor Control

Stop using your mouse or holding down the arrow key character-by-character. Use these combinations to fly through text documents, code editors, and input fields.

| Action | Windows OS | macOS |
| :--- | :--- | :--- |
| **Move word by word** | `Ctrl` + `Left` / `Right` | `Option` + `Left` / `Right` |
| **Select word by word** | `Ctrl` + `Shift` + `Left` / `Right` | `Option` + `Shift` + `Left` / `Right` |
| **Jump to start / end of line** | `Home` / `End` | `Command` + `Left` / `Right` |
| **Select to start / end of line** | `Shift` + `Home` / `End` | `Command` + `Shift` + `Left` / `Right` |
| **Jump to top / bottom of document** | `Ctrl` + `Home` / `End` | `Command` + `Up` / `Down` |
| **Delete entire previous word** | `Ctrl` + `Backspace` | `Option` + `Delete` |

## 🌐 4. Browser Productivity Essentials

These shortcuts work universally across all major browsers, including Chrome, Edge, Firefox, Brave, and Safari.

| Action | Windows OS | macOS |
| :--- | :--- | :--- |
| **Next / Previous Tab** | `Ctrl` + `Tab` / `Ctrl` + `Shift` + `Tab` | `Control` + `Tab` / `Control` + `Shift` + `Tab` |
| **Open new tab** | `Ctrl` + `T` | `Command` + `T` |
| **Close current tab** | `Ctrl` + `W` | `Command` + `W` |
| **Reopen last closed tab** | `Ctrl` + `Shift` + `T` | `Command` + `Shift` + `T` |
| **Focus address bar (URL)** | `Ctrl` + `L` / `Alt` + `D` | `Command` + `L` |
| **Refresh page** | `F5` / `Ctrl` + `R` | `Command` + `R` |
| **Hard refresh (clear cache)** | `Ctrl` + `F5` | `Command` + `Shift` + `R` |
| **Find on page** | `Ctrl` + `F` | `Command` + `F` |
| **Jump to tab #1–8** | `Ctrl` + `1` through `8` | `Command` + `1` through `8` |
| **Jump to last tab** | `Ctrl` + `9` | `Command` + `9` |

---

## 💡 Key Takeaways

1. **Multi-Screen Workflows:** On Windows, `Win` + `Shift` + `Arrows` is king. On macOS, set up **Rectangle** to achieve identical 1-key display jumps.
2. **Tab Control:** Standardize `Ctrl` + `Tab` / `Ctrl` + `Shift` + `Tab` for instantaneous tab navigation across browser tabs, terminals, and code editors.
3. **Text Mastery:** Combine `Ctrl`/`Option` with `Shift` + `Arrows` to highlight precisely what you want without reaching for the trackpad or mouse.
